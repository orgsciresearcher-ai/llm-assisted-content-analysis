# Codebooks

- `template.csv`: empty structure with one illustrative row (code, label, layer, group, definition, code_when, indicators).
- `case/codebook_A_original.csv`: the case codebook as it appears in prompt A, with labels and theoretical groups (17 governance-tension codes GT1.1 to GT5.4, of which GT2.4 and GT5.4 emerged inductively during calibration, and 3 skill codes SK1 to SK3).
- `case/codebook_B_delabeled.csv`: the same codes with neutral IDs and identical definitions, rules and indicators, as in prompt B. One definition (GT3.1 = L1-08) loses the phrase "as a governance dimension" (edit U15 in `prompts/case/change_log_A_to_B.md`).
- `case/mapping_A_B.csv`: mapping between both versions. It is used for analysis only and never enters prompt B.
